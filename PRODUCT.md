# Console Connect

<!-- impeccable:product-schema 1 -->

## Platform

web

Desktop application using web UI technology. Windows is the first tested release. Preserve a path to macOS and Linux, without claiming those platforms are verified.

## Stack

Electron and TypeScript, explicitly approved by the user. A bundled local coordination server supports computer hosting without Docker. Supabase is the other first-version hosting option.

## Users

People building software together, each using their own AI tools and subscriptions on their own computer.

## Product Purpose

Enable teammates to discuss, assign, approve, execute, and return reviewable work. Building software is central. Planning supports the work.

## Operating Context

Tasks belong to a Git repository. People work in separate local copies and task worktrees. Claude Code, Codex CLI, and Antigravity run in local terminal panels. Teams can operate across a private VPN or a hosted coordination service.

## Capabilities and Constraints

See docs/specification.md for the approved scope. Work requires recipient approval. Draft results stay private until submitted. Work-package acceptance and GitHub PR approval are separate. Terminal sharing is optional and view-only for teammates. Offline work synchronizes when connectivity returns.

## Brand Commitments

Name: Console Connect. The user selected the light Paper & ink Review Desk layout and editorial feel. Forest & linen, Blue & porcelain, and Ochre & parchment are selectable color themes. Preserve the shared typography and layout across them. Do not inherit Cockpit's product or branding.

## Evidence on Hand

The approved interview is captured in docs/specification.md. No customer evidence or performance claims exist.

## Product Principles

- Each person controls execution and sharing on their own machine.
- Shared decisions and reviewable results keep people aligned.
- Git owns code and document history. The coordination service owns collaboration records.
- A team can host its own workspace.
