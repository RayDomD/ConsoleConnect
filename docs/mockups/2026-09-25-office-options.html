Q17 · Seeing each other

Yes, this works. An Office where the team is together, built on the sharing you already have

Today you can watch one teammate's console, if they turn on "Share view only", from inside that task's Console tab. The Office puts everyone in one place: who's here, what they're on, and a glimpse of their console. Nobody can type into anyone else's session.

Already built

View-only live output from the task owner, no input route for viewers, and output kept in memory only, not saved.

Spec rules it keeps

Sharing is optional and controlled by the session owner. Watchers can comment, and comments go to the task discussion.

Limits to design for

Sharing works on computer-hosted workspaces only (Supabase isn't built yet). The spec also says to "limit and batch optional live streams" to keep hosting cheap.

Your choice, per person

"Show my console here" is a personal switch, remembered per computer. You can turn it off per session. Private sessions show only your name, task, and state.

View only, always

Watching never gives input. Comments go to the task discussion, and "Ask to watch" sends a request the owner can accept.

Light on streams

Cards get a three-line glimpse a few times a minute. The full live stream runs only while someone has the viewer open.

Both hosting modes

Office needs view-only sharing on Supabase too, which the spec already lists as remaining work.
