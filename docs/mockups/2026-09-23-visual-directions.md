Image mockups and exact generation prompts are saved under `.impeccable/mocks/`, named `deep-tide`, `paper-ink`, and `aubergine`. Each image uses `review-desk.png` as its layout reference. The mockups were generated with the built-in image tool. Prompt sidecars record provenance and remain unapproved.

Palette values are proposed tokens, not measurements of the generated images. Text, permissions, terminal prompts, and functional controls must follow the product specification when implemented. Colors must be sampled from the selected image and reconciled with accessibility requirements at that point.

The preview provides selectable options and full-size inspection. Image contents are illustrative, not running sessions or real team data. No app theme has been implemented or changed by this round.
