Q12 · Orchestrator context

When the orchestrator console opens, how does the tool learn the team, the tasks, and the rules?

Codex, Antigravity, and Claude Code each look for different instruction files (AGENTS.md, GEMINI.md, CLAUDE.md), so this choice decides whether the setup stays tool-neutral. Switch the tool in each window to see how it behaves.

AThe CLI explains itself, plus a typed-in openerRecommended

The app types a short opener (not sent) telling the tool to run console-connect brief. That command prints the team, roles, assigning rule, open tasks, and the command guide, live from the workspace.

Workers get the same approach

The task brief from Q6 ends with "run console-connect brief --task for the linked decisions and rules." Nothing is written to the repository.

What the brief contains

Team and roles, the assigning rule (Q11), open tasks and states, your auto settings (Q9), and which actions need your click (Q4).

Respects permissions

A Contributor's brief says they claim or suggest instead of assign, so the tool doesn't try what the host will reject.

Works outside the app too

In any terminal, running console-connect brief gives an outside tool the same picture.
