# Console in a dedicated task tab

Status: accepted

The terminal lives in the task's **Console** tab. The task title and status remain visible above tabs for Overview, Console, Package, and Discussion. An exited session stays visible, with a New console action in the tab header.

This keeps terminal output from pushing the package form and discussion down a long page. The selected design is [the console-tab mockup](../mockups/2026-09-23-console-tab.html).
